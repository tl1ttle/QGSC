# Third-party components

- `qgsc/monodromy/` is the locally used monodromy source tree, including a modified Windows LRS backend. It was copied from `Ising/monodromy`; it is not claimed as original QGSC code. No license file was present in that source directory. Its upstream license and attribution must be restored before public redistribution.
- ReQISC/Regulus and the LRS executable are external dependencies and are not bundled. Their original licenses apply.
- `benchmarks/` preserves the input files in `Ising/benchmarks`; this collection is not claimed as original QGSC material. Benchmark provenance and redistribution terms should accompany a public release.
- No license has been selected for the authors' code in this prepared folder.
